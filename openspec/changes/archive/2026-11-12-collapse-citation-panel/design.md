# 设计：按需展开的引用面板

## 显隐状态

引用面板的展开状态由对话视图持有，共三个字段：

| 字段 | 作用 |
|---|---|
| `openReferencesMessageId` | 当前展开的是哪条消息的引用；非空即展开 |
| `openReferences` | 该消息的引用快照 |
| `selectedReference` | 面板内选中的 chunk |

只有 `openReferencesMessageId` 非空且引用非空时才渲染面板，避免渲染空面板又立刻隐藏造成的闪烁。

## 面板宽度

`.chat-view` 的基础网格改为单列 `minmax(0, 1fr)`，展开态通过 `.chat-view--with-citations` 追加第二列 `minmax(18rem, 22rem)`。这样回答正文在无引用时获得完整宽度，展开时再让出右侧空间。

## 触发入口

- `ChatTranscript` 在每条含引用的助手消息结尾渲染一个按钮，文案为「引用来源（N）」，并通过 `open-references` 事件把消息 id 与引用列表抛给视图。
- 按钮的 `aria-expanded` 绑定当前展开的消息 id，便于读屏与自动化测试判断状态。
- 没有引用的回答不渲染按钮，避免出现点了没反应的入口。

## 与既有引用入口的关系

原实现同时存在「回答下方的引用 chip 列表」和「右侧面板」，点击 chip 会同步选中面板，属于同一份引用的两个入口。改为按钮展开后，chip 列表移除：按钮负责打开，面板列表负责选择与查看详情，引用反馈仍在面板详情内提交，且 target 仍绑定到该条回答的消息 id。
